Sistema de Gestión para un Taller Mecánico

Proyecto desarrollado en C++ utilizando archivos para almacenar información sobre servicios de reparación. El programa permite registrar reparaciones, consultar datos y generar distintos informes mediante el uso de programación orientada a objetos.

Pagina Web personal

Sitio web creado utilizando HTML5 con etiquetas semánticas para organizar correctamente el contenido. El objetivo del proyecto fue aprender la estructura básica de una página web antes de aplicar estilos con CSS.

Calculadora Básica

Aplicación desarrollada como práctica de programación para realizar operaciones matemáticas básicas como suma, resta, multiplicación y división. Este proyecto permitió reforzar conceptos de variables, funciones y estructuras de control.
